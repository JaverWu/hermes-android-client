会话列表

Telegram 式扁平行布局，发件人首字母相邻色渐变头像 + 名称 + 时间 + 双行预览 + 未读红点。点击任意项带头像进入对话。

未读消息采用高对比红点（≥ 3:1），而非仅靠颜色区分，照顾色觉障碍用户。

对话界面 + 神奇缩放

左灰右蓝气泡、已读双勾、输入中动画。底部「＋」蓝色圆键点击后，以 macOS 神奇缩放放大延展为全新会话。

缩放用 expo-out 贝塞尔（cubic-bezier(0.16,1,0.3,1)），尊重 prefers-reduced-motion。

玻璃悬浮标签栏

四周外边距 + 大圆角 + 毛玻璃模糊 + 细描边 + 软阴影。中间「＋」为蓝色上浮 FAB，激活态高亮。

毛玻璃实时响应列表滚动，iOS / Telegram 质感统一。

设置页

资料区 + 分组卡片（连接 / 外观 / 后台 / 关于）。每行图标 + 标签 + 副标题 + 箭头，点击区域 ≥ 44px。

分组边界用 1px 发丝线而非重卡片，降低视觉噪音。

无障碍与易用性

  • ✓对比度：正文 / 背景对比 ≥ 4.5:1，大字 ≥ 3:1，符合 WCAG AA。
  • ✓触摸目标：所有可点击元素 ≥ 44×44px。
  • ✓键盘可达：标签栏、按钮、输入框均可 Tab 聚焦，焦点环清晰。
  • ✓语义 HTML：导航用 <nav>，列表用 <ul>，图标配 aria-label。
  • ✓不依赖颜色：未读用红点 + 数字，状态用文字 + 图标。
  • ✓文字缩放：字号用 rem，支持浏览器放大至 200% 不破版。
  • ✓深色模式：非反色，用表面提亮 + 强调色降饱和营造层次。
  • ✓减少动效：动画尊重 prefers-reduced-motion 偏好。
